    4. Diagnostic

      Lire le tableau

      Ligne vide : l'objectif n'est pas évalué.

      Colonne vide : la question est à supprimer ou à rattacher.

      Total déséquilibré : le test ne reflète pas le poids des objectifs du module.

      Niveau de la question inférieur au verbe de l'objectif : la question vérifie moins que ce que l'objectif annonce.

      Trois fonctions

      P, positionnement : avant le module, score indicatif, oriente le parcours.

      AE, auto-évaluation : pendant le module, feedback explicatif, rien n'est enregistré.

      TF, test final : à la fin, score enregistré avec seuil, atteste l'atteinte des objectifs.

      Verbes mesurables

      Se souvenir : citer, reconnaître, identifier · Comprendre : expliquer, reformuler, classer · Appliquer : calculer, utiliser, remplir · Analyser : distinguer, diagnostiquer, repérer · Évaluer : juger, choisir, justifier · Créer : concevoir, rédiger, construire.

      À éviter : connaître, comprendre, savoir, maîtriser, être sensibilisé. On ne peut pas les observer.
