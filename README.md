# Tableau de spécification

Outil en une page pour vérifier l'alignement d'un test : objectifs en lignes, questions en colonnes, total par objectif, niveau visé, format et fonction de chaque question, diagnostic automatique.

Un seul fichier, `index.html`, sans dépendance serveur. Les données restent dans le navigateur de l'utilisateur.
